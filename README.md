# Gestura

Webcam hand tracking in the browser. Pinch thumb and index to click filters or draw on the video. Nothing is uploaded — it all runs locally.

React + Next.js. Needs a camera. Chrome or Edge works best.

## Run

```bash
git clone https://github.com/Eustack10/HandGesture.git
cd HandGesture
npm i
npm start
```

Then open the URL in the terminal (http://localhost:3000, or 3001 if 3000 is already in use) and allow the camera.

## Controls

Pinch = click. `1–6` filters, `D` draw, `C` clear, `S` snapshot, `?` help.
